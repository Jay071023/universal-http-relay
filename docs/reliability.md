# 移动端编辑与运行维护

## 修改节点权重

权重接受 1–10000 的整数。可先清空再输入，按键盘完成/Enter 或移开焦点保存。
空值和非法值不会提交为 1，保存失败时保留草稿；桌面按 Escape 可取消编辑。
实时推送按节点 ID 更新单元格，正在编辑的控件保留焦点和选择范围。

## QQ 统计

数据位于配置文件同目录的 `qq-stats/`；可用 `LB_QQ_STATS_DIR` 指定独立目录。
历史去重保存在 `all-qq.txt`，每日集合保存在日期命名的文本文件，`total.count` 保存总数。
今日数量按服务器本地日期更新，历史总去重不会每天增加同一个 QQ。
旧配置没有日期的 QQ 列表只迁移到历史集合，不作为今天的访问量。
追加队列约每秒刷盘；强制结束进程仍可能损失尚未写入的最后一批。
每日历史文件目前没有自动清理；配置备份也不包含这个目录，应另行备份统计数据。

## 健康检查和设置

HTTP 探针不重叠，消费响应体且不保留空闲探针连接。禁用节点不探测。
探针仍以收到 HTTP 响应作为在线依据，不保证业务响应内容正确。
配置批量校验全部通过后才应用；磁盘写入失败返回错误。
修改自动备份开关/间隔、Bark key/监控间隔后会重新设置对应定时器。
跨服务器监控列表在配置加载之后读取。

## 内存上限

服务按 RSS 监控进程内存，默认约 2.8 GiB（2867 MiB）；超过后每 15 秒采样一次，触发 SIGTERM 优雅退出并由 supervisor/PM2 拉起。
可通过 `LB_MAX_MEMORY_RESTART_MB` 调整阈值。PM2 配置同时设为 `2.8G`；当前非 PM2 运行模式由服务自身执行相同的 RSS 上限检查。

## 验证

后端及统计回归：`npm test`。
移动端交互回归：安装了 Playwright 且可以启动 Edge 的环境运行 `npm run test:ui`。
也可通过 `NODE_PATH` 指向已有的 Playwright 安装。UI 测试使用模拟 API 和 WebSocket 数据，
覆盖输入清空、连续推送后焦点保留、保存失败、筛选状态与设置输入保护，不连接生产服务。

Windows supervisor 记录退出并延迟重启；程序无法启动时的 `close` 事件也进入重试流程。
这不等同于系统服务：系统重启后的自启动、日志轮转和进程卡死检测仍需进一步完善。
